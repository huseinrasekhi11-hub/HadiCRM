# پنل وب HadiFlow (نسخه اول — ورود + داشبورد)

این یک پروژه‌ی جدا از بک‌اند شماست (React + Vite) که به API فعلی HadiFlow وصل می‌شود.
هیچ تغییری در دیتابیس یا منطق بک‌اند نداده — فقط دو فایل به `app/main.py` اضافه شد
(فعال‌سازی CORS تا مرورگر اجازه‌ی تماس با API را بدهد).

## پیش‌نیاز
- Node.js نسخه ۱۸ به بالا (برای اجرای پنل)
- بک‌اند HadiFlow روی حالت اجرا (معمولاً با `uvicorn app.main:app --reload` روی پورت ۸۰۰۰)

## اجرای محلی

۱. نصب پکیج‌ها (فقط بار اول):

```bash
npm install
```

۲. مطمئن شوید فایل `.env` آدرس درست API را دارد:

```
VITE_API_BASE_URL=http://localhost:8000
```

اگر بک‌اند روی پورت یا آدرس دیگری اجرا می‌شود، این مقدار را تغییر دهید.

۳. اجرای پنل:

```bash
npm run dev
```

سپس آدرس نمایش داده شده در ترمینال (معمولاً `http://localhost:5173`) را در مرورگر باز کنید.

## نکته مهم درباره‌ی بک‌اند

به فایل `app/main.py` این بخش اضافه شده تا مرورگر بتواند به API وصل شود:

```python
app.add_middleware(
    CORSMiddleware,
    allow_origins=[
        "http://localhost:5173",
        "http://127.0.0.1:5173",
    ],
    allow_credentials=True,
    allow_methods=["*"],
    allow_headers=["*"],
)
```

اگر بعداً پنل را روی سرور واقعی (دامنه‌ی مشخص) میزبانی کردید، باید آدرس آن دامنه
را هم به لیست `allow_origins` اضافه کنید — در غیر این صورت مرورگر درخواست‌ها را
مسدود می‌کند.

## چه چیزی الان کار می‌کند

- صفحه‌ی ورود: با شماره موبایل و رمز عبور (دقیقاً مثل تنظیمات فعلی auth شما)
- داشبورد:
  - برای نقش‌های `admin` / `ceo`: آمار کلی + نمودار مسیر قیف فروش (پایپ‌لاین لیدها)
  - برای بقیه‌ی نقش‌ها: تعداد لیدها و وظایف شخصی
- خروج از حساب

## چه چیزی هنوز نیست (مرحله‌ی بعد)

- صفحه‌ی لیست لیدها و جزئیات هر لید (تایم‌لاین، وظایف، پیوست‌ها، تغییر وضعیت، ارجاع)
- صفحه‌ی وظایف
- مدیریت کاربران

اگر ظاهر و رفتار داشبورد را پسندیدید، این بخش‌ها را به همین سبک اضافه می‌کنیم.

## ساختار پوشه‌ها

```
src/
  api/client.js        تماس با API + مدیریت توکن
  context/AuthContext   وضعیت ورود کاربر در کل برنامه

  pages/                صفحات (ورود، داشبورد)
  leadStatus.js         برچسب و رنگ مراحل قیف فروش
```
